随机海岛 自由建造 离线单人

探索随机海岛，拆除或放置方块自由建造；地图与设置保存在 SD 卡中。

玩法 自由探索与建造

  • 探索随机生成的海岛。
  • 从物品栏选择方块。
  • 拆除、放置方块并自由搭建。

应用信息 版本与大小

版本号1.0.0
安装包大小2.91 MB

手柄 按键操作

左摇杆 / 十字键移动
右摇杆转动视角
A跳跃；菜单中确认
B / SELECT返回或关闭
X打开物品栏
Y拾取准星所指方块
RT / L1拆除方块
LT / R1放置方块
L3 / R3上一个 / 下一个快捷栏格
START / HOME暂停 / 退出应用
提示：掉出海岛边缘或落到地图下方时会自动重生；暂停菜单使用十字键移动、A 确认。
