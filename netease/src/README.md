# 网易云音乐 / ESP32-S3

独立 App，所有实现和依赖均在本目录所属的 netease 内。不修改其它 App 或固件。
将 ../package 内容上传到 /sd/apps/netease，重扫应用后启动 netease。

当前发布版本：**1.0.0**（应用清单、说明页与动态模块版本一致）。

0.1.3：播放地址独立通道、短期地址缓存和下一首地址预取；歌词/封面与浏览请求分离。
地址缓存最多 3 首、最长 115 秒（QQ 地址实际 55 秒），仅内存保存，退出账号时清空；
歌词最多缓存 3 首。元数据与后台请求错开启动，播放缓冲优先。
排队 10 秒、API 首包 10 秒/联网总计 20 秒分别计时；音频首包 7 秒，传输空闲 10 秒。
取地址瞬态错误最多 2 次；CDN 尚未输出 PCM 时最多 2～3 次尝试，已输出后不从头自动重播。
权限错误不盲目重试；CDN 401/403 只允许重新获取一次地址。备用域名仅采用平台返回并通过校验的节点。
`/status` 的 playback_phase、url_resolution、url_request、playback_timing、metadata_request
区分排队、地址、CDN 首包及首次 PCM 写入，不输出签名播放地址；首次 PCM 写入不等同于麦克风测到出声。

图标原图保存在 `src/assets/icon-source.png`，透明编辑版位于 `src/assets/icon-transparent.png`；
`src/build_icon.ps1` 生成保留 Alpha 的 96×96 PNG、按黑底合成的 RGB565 启动 BMP，并同步说明页 Base64。
启动页使用 `/sd/...` 预加载句柄，设置图片后再显示，构建主界面时清理句柄；失败显示文字，
不显示未解析图片。固件会处理 Lua 图片路径，不能把偶发白图直接归因于缺少 S: 前缀。
`package/info.html` 为独立说明页，图标以内嵌 Base64 保存；测试会核对其与 main.png 字节一致。

0.1.1：网页“回到主页”使用同源 `/main`，不硬编码设备 IP。
启动先检查 `sys.version()`，要求系统固件 1.211 及以上；低版本、缺少版本 API 或
无法识别版本时显示“请更新到最新系统固件”，长按 Home 退出，不加载播放器模块或登录数据。
版本分段按整数比较，不使用浮点数；1.211 预发布标记不视为正式 1.211。

## 架构

- Lua/LVGL：纯黑界面、交互、业务状态和 HTTP 分块接收。
- ncm_music.so：EAPI 请求加密、本地二维码生成、384 KiB PSRAM 压缩流缓冲、
  MP3 解码、原生采样率单声道输出、5 段 EQ、HPF、虚拟低音、I2S。
- 不经过第三方 API 代理；不实现会员或版权限制绕过。
- 网易云请求 level=standard、encodeType=mp3。实际返回非 MP3 或试听时明确拒绝。
- 不做额外降采样。以解码器报告的实际采样率配置 I2S，常见为 44.1 kHz。
- 每条网络通道只保留一个活动连接，切换时等待取消完成；环形缓冲满时 DELAYACK，
  保存最多一个未消费网络分块，腾出空间后送入模块并 ack。

32 位 Lua 将账号/歌曲 ID 溢出或舍入；不会读取或显示凭据进行诊断。
摇晃阈值 24°、回中 10°、650 ms 冷却；方向可在 model.lua 中按实际安装方向调整。
歌单列表和歌曲详情按 20 项分页；歌单 ID 响应有 512 KiB 限额。

（共三次，间隔 1 秒/2 秒）。确认无歌词或三次均失败才显示“暂无歌词”。
空时间戳行、空格/制表符/全角空格等纯空白歌词行会被过滤，不占用显示行。
切歌隔离旧响应，元数据请求被浏览操作打断时允许后续重试；歌词失败不报音频错误。
网页与设备使用同一歌词状态；网页状态接口提供 lyric_status、lyric_attempts 和 lyric_generation。
歌名用 13px 字体，固定两行 36px 区域，超长省略；歌手区与歌名区分离，避免重叠。
右上角显示设备本地时间与实际采样率（如 15:30 · 44.1k）；本地时间直接使用
time.getlocal()，沿用系统 TZ/DST，不自行叠加夏令时偏移。未同步显示 --:--。
UI 仅在最终值变化时提交文字/显隐/颜色；布局仅切页时更新，避免 100ms 刷新闪烁。
换封面后重新设置左上角缩放基准点，避免 LVGL 重置到中心造成偏移。
封面对象默认隐藏；换图时先隐藏，再提交图片源、缩放和位置，最后显示，避免
异步 UI 队列绘制中间状态时短暂闪出白色 No data。无图或图像句柄失败时保持隐藏。
歌单与歌曲列表保留封面；缩略图使用 PSRAM 热缓存和 SD 持久缓存，低缓冲时让音频优先。
音乐库页会后台预取当前栏目的首曲封面，使用账号数据；不需先进入歌曲列表。
封面最多保留四项，单图接收上限 96KiB（98,304 字节）；失败按延迟最多尝试三次，重入栏目可重试。
设备统一请求 `?param=92y92` 缩略图；播放页显示 92×92，音乐库/列表页放大到 128×128。
按文件签名识别 JPEG/PNG，不相信 URL 后缀或 Content-Type；两种格式均可缓存到 SD。
缓存标识保留尺寸参数，旧 136×136 缓存不冒充新 92×92 缓存，也不主动清空；
首次访问会下载并保存 92×92 版本，旧缓存继续计入 10MiB 配额并按 FIFO 自然淘汰。
网页浏览器独立的 320×320 封面请求不变，不占设备接收缓冲和 SD 缓存。
PNG 校验 IHDR 尺寸、块边界和 IEND，尺寸仍限制为 136×136；固件解码器继续校验 CRC 和压缩数据。
PNG 由本 App 原生模块包装为 LVGL 8 图像 userdata（描述符和压缩数据同一块 PSRAM），
复用现有固件 PNG 解码器；UI 持有引用直到换图/清屏，避免裸指针悬空，无需修改固件。
96KiB 是压缩文件上限，不是解码内存上限；PNG RGBA 解码输出最多约 72.3KiB，
另有解码工作区，批量缓冲走宿主 PSRAM 分配器。图像句柄错误见状态接口 ui_cover_error。
这里的四项是内存热缓存；SD 缓存位于 `/sd/data/netease/covers`，文件内容总量
上限 10MiB（含缓存头，不含 FAT 簇对齐开销）。优先读取 SD，命中时不再联网下载图片。
空间不足按首次写入顺序淘汰最早的封面，读取不会刷新顺序；重启后从文件名恢复顺序。
新文件先临时写入并回读校验，再重命名提交；损坏缓存重新下载，SD 不可用时退回联网。
缓存只管理专用目录内本 App 格式的封面文件，不删除会话、设置或其它文件。
已确认等价的 p3/p4.music.126.net 使用同一个内存/SD 缓存标识，实际下载仍用
接口返回的域名；图片路径和尺寸参数保留，其它域名不合并。旧缓存无需清空或
重写：最多检查两个旧哈希索引，优先读取最早有效文件，保留原 FIFO 顺序。
已存在的重复文件不主动清理，仍计入 10MiB 配额并按原顺序自然淘汰。
无账号凭据或封面 URL 的诊断计数见 /netease/status 中 covers 字段。
上下循环切换播放、音乐库、说明页；说明页 Home 回到播放。
尚无拖动定位、后台播放或音频文件缓存。
音频断流时显示错误，Home 从头重试；尚未实现 Range 无缝续传。

## EQ / 虚拟低音

设备网页 /netease/ 提供 EQ 和虚拟低音调节，右上角可返回设备主页。
网页歌曲列表独立于设备页面保存，点击播放、暂停、切歌或设备切页不会清空列表；
可以继续选择其它歌曲和翻页。列表版本仅在换栏目/翻页时更新，拒绝旧列表点击，
播放状态变化保留列表滚动位置，并按实际播放歌曲标记当前行。
网页新增随机播放、顺序播放和单曲循环按钮，模式保存在 settings.json。
顺序播放到队列末尾停止；单曲循环只影响自然播完，手动上下首仍可切歌；
随机播放在多首队列中避开立即重复当前歌曲，单首队列可继续重复播放。
参数应用后保存到 settings.json；编辑文件后需重新进入 App。
五段为 180 / 420 / 1000 / 2500 / 4300 Hz，各 -6 至 +6 dB。
默认 +6 / +3.6 / -1.4 / -1 / +0.5 dB，是用户七段曲线的近似，不是精确等效。

默认 HPF=100 Hz，虚拟低音开启，mix=0.25，drive=3.5，
提取 50–180 Hz，谐波输出 120–600 Hz。默认文件见 ../package/settings.lua。

节省计算：

- 先混合单声道，滤波链只运行一套。
- 系数仅在开始解码、采样率确定后重算，不在逐采样路径调用三角/幂函数。
- 零增益 EQ 不执行滤波；关闭虚拟低音/mix=0 时跳过整个低音支路。
- 整流与三次多项式生成谐波，不使用逐采样 tanh/FFT。
- 正增益前预留余量并限制输出峰值，避免溢出；并非动态压缩器。
- 输出增益相对上一部署再提高 2 倍（相对原始 PCM 基准为 4 倍），音量刻度保持
  0–100。仍在 int16 转换前钳位到 ±32112；大音量可能触发削波，主观响度不保证翻倍。
- 参数只能在解码任务停止时修改，避免与工作线程竞争。

## 内存与固件要求

需要 Host ABI v3（0x00030000）、ESP32-S3、PSRAM、I2S，以及支持异步 HTTP、
DELAYACK 和证书验证的当前 Cubic 固件。I2S 引脚沿用现有播放器：
DOUT=48，其它 -1 由宿主采用设备默认值，6 × 512 DMA 帧。
网络音频接收块 6KiB，压缩环形缓冲 384KiB、PCM 暂存 4KiB 均使用 PSRAM。
按 16-bit 单声道计，DMA 音频数据约 6KiB，由宿主在适合 DMA 的内部内存中管理。
384KiB 非二次幂容量使用独立物理读写位置，不依赖会绕回的 32 位累计字节计数取模。

模块的 malloc/calloc/realloc 强制 PSRAM，无内部 RAM 回退。状态、codec heap、
协议/QR 工作区、压缩流和 PCM 暂存均在 PSRAM。工作任务栈 8192 字节、
DMA/TCB 等必要资源由宿主管理。

50 KiB 仅是用户提供的**内部 RAM 大致占用参考**，不是硬限制。
Lua 和原生模块均不再因超过 50KiB 而停止或拒绝播放；保留内部 heap 基线、当前空闲值
和峰值增量诊断，实际分配失败、解码/I2S 错误仍正常处理。其它服务会影响全局差值。
TLS 在宿主中分配，短暂握手尖峰、Lua 加载之前的分配和系统并发不能靠周期采样
完整证明上界。需要结合实机稳定播放、扫码握手和长期切歌测试验收。
