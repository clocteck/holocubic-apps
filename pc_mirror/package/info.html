纯 Lua 局域网投屏

Pure Lua LAN mirroring

电脑投屏PC Mirror

通过 WebSocket 接收电脑端 JPEG 画面，并实时显示到设备的 320×240 屏幕。

Receives JPEG frames over WebSocket and displays the PC desktop on the device's 320×240 screen.

使用方法

How to use

  1. 1启动电脑端安装上游仓库依赖，运行 computer\start_mirror.bat --fps 20 --quality 65。
  2. 2打开内置 Web 页面启动“电脑投屏”，在浏览器打开设备屏幕显示的 SETUP 地址。
  3. 3保存并自动重连填写电脑端打印的 IPv4 地址和端口，点击保存即可，无需手动修改配置文件。
  1. 1Start the PC senderInstall the upstream dependencies and run computer\start_mirror.bat --fps 20 --quality 65.
  2. 2Open the built-in Web pageStart PC Mirror, then visit the SETUP address shown on the device.
  3. 3Save and reconnectEnter the PC's printed IPv4 address and port. The app saves it automatically; no manual file editing is needed.
