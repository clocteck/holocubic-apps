# 电子书 / E-Book（Clocteck Cubic）

面向 320×240 ESP32-S3 设备的低内存 EPUB/TXT/Markdown 阅读器。

当前版本：0.4.0。新增 EPUB 图片页：浏览器提取、缩放并转换图片，设备按需从 SD 卡显示，不在 MCU 上执行图片转换。

## 大文件策略

- 书库位于 `/sd/ebooks`，应用更新不会覆盖用户书籍。
- 打开书籍时只 `seek` 到当前 byte offset，再读取约 4 KB 完成当前页排版。
- 不预先分页、不整本载入内存；上一页使用最近 128 个页面 offset，退出时保存最近 32 个。
- 首次打开时，后台定时器每 20 ms 扫描 8 KB，只保存章节标题和 byte offset。
- 章节目录以紧凑二进制 `.idx` 保存在 `/sd/ebooks/.index`，记录文件大小、CRC、快速指纹、章节标题和 byte offset；文件未变化时直接加载，不再扫描全文。
- 阅读位置单独保存在 `/sd/ebooks/.reader_state.json`，正文页面继续动态分页，只缓存最近页面的 byte offset。
- 索引器将单行缓冲限制为 512 bytes，异常超长行不会持续占用内存。

## EPUB 策略

- Web 控制页使用浏览器原生 ZIP/Deflate 能力读取 EPUB 的 `container.xml`、OPF、spine、NAV/NCX 和 XHTML 正文。
- 转换结果保存为 `/sd/ebooks/.epub/<hash>/sections/*.txt`，书库入口是一个很小的 `.epubbook` JSON 清单。
- EPUB 插图保存为 `/sd/ebooks/.epub/<hash>/images/*`；正文锚点把图片作为独立页面插入原位置。
- 图片只缩小、不放大，最大适配正文区域 `296×174`；照片转换为 JPEG，PNG/SVG/GIF 转为静态 PNG。
- 清单记录书名、作者、章节标题、章节文件、大小和全局 byte offset；再次打开直接载入目录，不扫描全文。
- 页面仍采用动态分页，翻过章节末页会自动打开下一章节；EPUB 图片按原位置显示为独立图片页。
- 缓存布局借鉴 CrossPoint Reader 的“书籍元数据 + 分章节缓存”设计，但实现为适合 Lua 动态应用和固件 FS API 的轻量格式。
- 当前不实现文字环绕、动图播放和复杂 CSS；GIF 取静态首帧，SVG 在浏览器端栅格化。

## 输入

- 设备/陀螺仪：使用与 Launcher 相同的 `key.LEFT`、`key.RIGHT` 事件及长按重复节奏。
- 手柄：与 Launcher 一样，每 40 ms 读取 `controller.state("ble-main")`。
- 左右：翻页；A：章节目录/确认；START：书库/切换菜单；B：返回；SELECT 或 HOME：退出应用。

## 格式和字体

- 原生读取 UTF-8 TXT、Markdown，以及网页预处理后的 EPUB 章节缓存。
- Web 上传页可在电脑或手机浏览器中把 GBK/GB18030、UTF-16LE/BE 转换为 UTF-8，再经固件 FS 接口上传。
- 设备只渲染当前页，使用 LVGL 二进制中文字体，不使用 Retro-Go 旧式线性中文字形扫描。

## 设备实测（192.168.0.218）

3,301,492 bytes、800 章中文 TXT：首屏 135 ms；后台目录完成 18.86 s；索引期间翻页 184 ms。测试书随后已删除。

真实 EPUB 测试：52 章、46 张插图均成功生成缓存，支持文字页与图片页双向翻页，重启后可恢复图片页。

## 0.4.0 更新说明

- 新增 EPUB 2/3 文字内容导入。
- 新增 EPUB 封面与正文插图显示。
- 浏览器端自动提取、缩放和转换图片，降低设备端内存与计算压力。
- 新增持久章节、图片和目录缓存，大型电子书再次打开无需重新索引。
- 新增字号、文字颜色、书库、目录和阅读进度 Web 管理。
- 支持简体中文、繁体中文、英文和日文界面。
- 支持陀螺仪、设备按键和蓝牙手柄翻页、打开目录及退出应用。
- 修复 EPUB 删除时可能影响其他缓存目录的问题。
