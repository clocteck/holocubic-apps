# Holo Clock

Holo Clock 是面向 HoloCubic 的多表盘桌面时钟，包含天气、月相、备忘录、烟花时钟和经典电子管表盘。

## 1.2.0 更新说明 / Release Notes

- 中文：增加烟花时钟的语言支持，星期会根据设备系统语言显示，支持简体中文、繁体中文、英文和日文。
  English: Adds language support to the Fireworks clock. Weekdays now follow the device system language, including Simplified Chinese, Traditional Chinese, English, and Japanese.
- 中文：增加烟花时钟的天气和温度显示，采用天气图标、天气文字和温度计图标组合，并保持整体居中。
  English: Adds weather and temperature display to the Fireworks clock, using centered weather and thermometer icon groups.
