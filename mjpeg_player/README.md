# MJPEG 视频播放器

面向 Clocteck Cubic 320×240 设备的有声 MJPEG-AVI 播放器。Lua 负责 AVI 容器解析、SD 卡顺序读取、按键与 20 FPS 源时间轴；`jpg.so` 调用 ESP32-S3 ROM JPEG 解码器并转换为 RGB565，再通过 LVGL 安全图像缓冲显示；`audio.so` 播放与 AVI 同名的 16 kHz 单声道 WAV 音轨。

## 0.2.8

- 蓝牙手柄 `SELECT` 或 `HOME` 现在会先安全停止音频、异步解码和显示资源，再退出播放器。

## 0.2.7

- 恢复异步 JPEG 解码和音频流水线，避免同步解码长期占用 Lua/UI 线程导致 Web 清理接口超时。
- `jpg_decode` 改为“请求停止、等待任务确认退出、再继续析构”，并将内部任务栈由 16 KB 缩减到 8 KB，为固件退出清理保留内存。
- 成帧画面交给现有 LVGL 图片对象显示，不再直接接管面板，退出时无需重新分配 LVGL 双缓冲，避免内存碎片导致黑屏。
- 每帧解码后主动让出一个调度 tick，避免持续满队列使 CPU1 空闲任务无法喂看门狗。
- Launcher 的 Web 退出会先调用播放器安全退出接口；清理失败时不再强制销毁 Lua 状态。

## 0.2.6

- 改为从 Lua 更新线程同步调用 `jpg.so` 解码/显示，并以非阻塞方式调用 `audio.so` 填充 I²S，不再创建每次播放独有的三个原生后台任务。
- 避开固件动态任务包装层退出后未完全回收资源的问题，连续 Web 退出和重新打开不会再因任务创建失败而中断。
- 保留 Web 安全退出确认和 20% 默认音量。

## 0.2.5

- `jpg_decode` 停止后改由 Lua 更新线程从外部删除，不再让原生任务自删，避免固件的任务清理助手创建失败后泄漏资源。
- Web 退出会验证音频与 JPEG 原生任务均已停止；清理失败时拒绝继续强制销毁 Lua 状态。
- 安全退出接口改为 `POST /api/mjpeg-player/prepare-exit`，避免无控制页应用的相对路径被固件重定向到 `/main`。

## 0.2.4

- 新增 Web 安全退出预处理：Web 控制页先停止音频和 JPEG 任务，再调用固件退出接口。
- 修复 Web 的 `/api/system/exit` 直接销毁 Lua 、跳过清理，导致再次打开时原生任务创建失败。

## 0.2.3

- HOME 改为由播放器先完成清理再调用 `app.exit()`，避免固件自动退出先销毁 Lua 状态。
- 停止音频时等待 `audio_fill` 和 `audio_i2s` 两个原生任务真正退出，再关闭 I2S 与文件，修复退出后 panic 及再次打开任务创建失败。
- 解码任务创建失败后不再每帧重试，避免日志与内存被持续消耗。
- 默认测试音量调整为 20%。

## 0.2.2

- 改用原生异步解码 + LVGL 安全图像缓冲，不再跨帧占用直写屏幕所有权，避免固件直接销毁 Lua 状态时 Launcher 黑屏。
- 直接解析 WAV `fmt ` 块中的采样率、声道数和位深，避免 `audio.so` 将 16 kHz 音轨误报为 44.1 kHz 导致音频过快。
- HOME 退出与运行时退出检测仍会主动停止定时器、解码任务和音频。

## 0.2.1

- HOME 退出前主动停止定时器和原生任务，并释放直写屏幕句柄。
- 应用运行时检测固件退出状态，提前执行相同清理逻辑。
- 屏幕释放优先于音频关闭，退出阶段不再强制执行完整 Lua GC。
- 修复退出后直写屏幕仍由 `desktop_mirror` 占用、Launcher 与其他应用黑屏的问题。

## 视频要求

- AVI 容器，视频编码为 MJPEG（FourCC `MJPG`/`JPEG`/`dmb1`）
- 推荐 320×240、20 FPS 源视频；当前安全显示模式在测试设备上实际约 13–14 FPS
- 兼容 160×120，解码后放大到 320×240 显示
- 播放时间轴按源文件帧率运行，落后时跳过旧帧以维持音画同步
- 基线 JPEG，不支持渐进式 JPEG
- 自动播放 `/sd/videos` 中与 AVI 同名的 WAV 音轨，例如 `demo.avi` + `demo.wav`
- 暂停、恢复、切换视频和循环播放时同步控制音轨
- 文件放到 `/sd/videos`

推荐使用 FFmpeg 转码：

```powershell
ffmpeg -i input.mp4 -vf "fps=20,scale=320:240:force_original_aspect_ratio=decrease:flags=lanczos,pad=320:240:(ow-iw)/2:(oh-ih)/2:black,setsar=1" -an -c:v mjpeg -q:v 7 -pix_fmt yuvj420p output.avi
```

## 按键

- 左/右：切换视频
- 上：暂停/继续
- 下：显示或隐藏性能信息
- HOME：退出应用

播放器以 20 FPS 为目标。设备落后于时间轴时会跳过旧帧，避免整段视频持续变慢。

## 设备实测

在固件 1.203 的测试设备上，320×240、20 FPS MJPEG 使用 0.2.7 的 LVGL 安全显示路径时，实际显示约 13–14 FPS。播放器会依据 20 FPS 源时间轴跳过过期帧，避免音画延迟不断累积。连续执行 Web 退出并重新打开测试时，原生任务可正常停止和重建，未出现返回桌面黑屏、任务创建失败或看门狗重启。
