# QQ 音乐 / Cubic 320×240

独立目录 `qqmusic`。设备界面沿用网易云的左封面、五行同步歌词、底部进度布局，
改为 QQ 音乐绿。HTTP 背压、MP3 / DSP、字体和封面缓存为本地 netease 的独立副本。
不需要安装 netease，也不修改它或设备固件。

## 使用

- 未保存登录会话时，启动直接显示 QQ 二维码。
- 左右切换 QQ / 微信；短按 Home 跳过；长按 Home 退出。
- 游客仅有热歌榜、新歌榜；登录后增加收藏、每日推荐、最近播放。
- 收藏读取账号“我喜欢”；每日推荐读取“今日私享”歌单入口，平台未返回时显示错误。
- 最近播放明确为当前账号的**本机**记录，最多 50 首，实际开始播放后记入，不写云端。
- 左右选歌/换歌，上下切页，Home 确认/暂停；手柄输入沿用原布局。
- 控制网页：`http://设备IP/qqmusic/`，提供扫码切换、音乐库、音量、五段 EQ 与虚拟低音。
- 网页歌单与设备页面分离，播放/暂停/换歌不清空列表、不重置滚动位置；旧分页点击校验独立列表版本。
- 登录/恢复会话后默认进入收藏并加载；空闲时分批预取完整收藏、热歌榜、新歌榜（自动预取每栏最多1000首）。
- 栏目内存缓存避免来回切换重复加载；热歌/新歌元数据以20首一页保存至SD，6小时有效，过期缓存先显示再空闲刷新。
- 网页有顺序播放、随机播放、单曲循环按钮；随机选择当前队列并避免连续重复同一首。
- 同步歌词剔除空白、全角空格或只有时间戳的行，设备和网页共用过滤结果。
- 顶部显示真实账户昵称，点击查看登录方式、头像、平台返回的会员信息，并可退出本设备登录。
- 搜索接口目前游客实测可能返回空结果，显示明确提示；不伪造搜索结果。

## 包、构建、测试

`package/` 内容部署到 `/sd/apps/qqmusic/`。`src/` 为源码、构建、测试和资料。

0.1.1：网页“回到主页”使用同源 `/main`，不硬编码设备 IP。
启动先检查 `sys.version()`，要求系统固件 1.211 及以上；低版本、缺少版本 API 或
无法识别版本时显示“请更新到最新系统固件”，长按 Home 退出，不加载播放器模块或登录数据。
版本分段按整数比较，不使用浮点数；1.211 预发布标记不视为正式 1.211。

```powershell
./qqmusic/src/build.ps1
python qqmusic/src/tests/test_app.py
node qqmusic/src/tests/test_web.js
./qqmusic/src/deploy.ps1 -Device http://192.168.0.226
```

部署脚本默认不关闭其他 App；明确授权切换前台时可传 `-SwitchApp`。
依赖 ESP32-S3 工具链、ESP-IDF/IDF_PATH；测试使用 Python + lupa。
独立输出 `package/modules/qq_music.so`。C 内部 ncm_* 名称保留用于复用已验证 DSP/缓冲实现。

## 资源和限制

- MP3 128k 档（M500），仅接受平台返回的有效播放地址；权限不足明确报错，不绕过会员/版权。
- PSRAM 压缩环形缓冲 384KiB，PCM 暂存 4KiB，6×512 DMA，保留解码器原采样率、单声道输出。
- 内部 RAM 增量 50KiB 仅为参考，不是硬限制；Lua和原生线程均不再据此停止播放，保留统计和真实内存分配失败处理。
- 封面签名识别 JPEG/PNG、单张最多96KiB、4项热缓存；10MiB FIFO SD缓存，仅管理自身文件。
- 缩略图请求 QQ CDN 90×90。二维码与封面尺寸验证分离，QR 最长边512、压缩文件96KiB。
- SD数据：`/sd/data/qqmusic/session.json`、`settings.json`、`recent.json` 及其备份；封面在 covers/。
- 安装不覆盖账号数据。SD凭据为敏感明文，勿公开设备端口或分享会话文件。
- 不实现会员绕过、微信/QQ凭据跨域转发、后台播放、拖动定位或 QQ 音乐 App MQTT 扫码。

扫码细节与来源见 [docs/login.md](docs/login.md)。
实测结果与尚未打通的接口见 [tests/device-results.md](tests/device-results.md)。
编解码器、MbedTLS、二维码库的许可证保留在 `vendor/`；字体许可证位于 package/font/OFL.txt。
