QQ 音乐

熟悉的歌，放在桌面听。设备选曲、同步歌词，也能用浏览器遥控。

v1.0.0ESP32-S3 · 320×240系统固件 ≥ 1.211标准 MP3
01 / ACCOUNT

扫码，把音乐带过来

支持手机 QQ、微信扫码登录；启动二维码可左右切换，短按 Home 可跳过。游客可浏览热歌榜、新歌榜。

02 / LIBRARY

常听的歌，少一点等待

登录后默认加载收藏。提供热歌榜、新歌榜、收藏和最近播放；最近播放是当前账号的本机记录，最多 50 首。

03 / PLAYER

封面与歌词，跟着歌曲走

显示专辑封面、五行同步歌词与播放进度。支持顺序、随机和单曲播放，网页列表在播放后保留。固定请求普通音质 M500 / 128kbps MP3。

04 / CONTROL

小屏听歌，网页调音

浏览器可选曲、调音量、切播放模式，设置五段均衡器与虚拟低音；账户弹窗显示平台返回的会员信息，并可退出登录。

设备操作

左右操作选择歌曲 / 切换音乐库
上下操作切换页面 / 返回音乐库
短按 Home确认 / 播放暂停
长按 Home退出应用

缓存与隐私

播放地址、歌词和浏览请求按优先级调度。最多保留 3 首短期播放地址与 3 首歌词，缓存仅在本次运行中使用；预取下一首地址不等于下载整首歌曲。

封面单张上限 96KiB，SD 封面缓存总量 10MiB，按先进先出清理。账号与设置独立保存在 /sd/data/qqmusic/，更新 App 不覆盖该数据目录。

凭据在 SD 卡上为敏感明文；不要分享账号文件，也不要把设备控制端口暴露到公网。本 App 直接连接音乐平台，不使用第三方账号代理。

需要 Wi-Fi、SD 卡及系统固件 1.211 或更新版本。歌曲能否播放取决于账号权限、地区和平台服务；不绕过会员、版权或试听限制。音频设备被其他服务占用时，请先停止冲突服务。
