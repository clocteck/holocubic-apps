从电脑到屏幕

From PC to display

首次使用按顺序完成；以后只需启动电脑端脚本并打开应用。

Follow these once. Later, start the PC sender and open the app.

  1. 1安装电脑端环境电脑安装 Python 3，下载下方开源仓库，在仓库根目录运行依赖安装脚本。computer\install_deps.bat
  2. 2启动桌面推流脚本会捕获主显示器，输出 320×240 JPEG，并打印可连接的 ws://电脑IP:8787 地址。computer\start_mirror.bat --fps 20 --quality 65
  3. 3打开应用和本页电脑与设备连接同一局域网。在 Launcher 打开“电脑投屏”，再用手机或电脑浏览器打开设备屏幕显示的 SETUP 地址。
  4. 4保存电脑 IP在右侧填写电脑端打印的 IPv4 地址和端口，点击“保存并重连”。连接成功后画面自动替换等待页。
  1. 1Install the PC environmentInstall Python 3, download the source repository, and run the dependency installer from its root.computer\install_deps.bat
  2. 2Start desktop streamingThe sender captures the main display, emits 320×240 JPEG frames, and prints a ws://PC-IP:8787 URL.computer\start_mirror.bat --fps 20 --quality 65
  3. 3Open the app and this pageKeep both devices on one LAN. Open PC Mirror in Launcher, then open the SETUP address shown on the device.
  4. 4Save the PC addressEnter the printed IPv4 address and port, then choose Save & reconnect. The stream replaces the waiting screen after connection.

常见问题与进阶参数

Troubleshooting and advanced options

绝大多数问题来自 IP、Windows 防火墙或电脑端未持续运行。

Most issues come from the wrong IP, Windows Firewall, or a stopped PC sender.

一直显示 OFFLINE确认电脑端窗口仍在运行、两端同网段，并使用电脑当前 IPv4 地址。

选择其他显示器先运行 --list-monitors，再加 --monitor 2 指定编号。

Always OFFLINEKeep the sender window running, verify one subnet, and use the PC's current IPv4 address.

Choose another monitorRun --list-monitors, then add --monitor 2 with the desired index.
Aspect ratioThe default fills 320×240. Use --fit contain on the PC to preserve the source ratio.
