# Launcher 1.23

部署文件位于 `launcher/package/`，安装到设备的 `/sd/apps/launcher/`。

## 1.23 更新内容

- 从控制页启动应用后，每 `500 ms` 刷新一次系统状态，最长持续 `5 秒`。
- 检测到目标应用的 WebUI 路由后立即停止轮询，并及时显示“应用页面”入口。
- 普通状态下不进行长期后台轮询。

## 1.22 更新内容

- 新增指示灯颜色与 RGB 亮度设置，并由网页一次性提交缩放后的 RGB 值。
- 静态图片上传前自动按比例适配到 `320×240` 范围。
- 固件更新期间恢复实时进度，并且只在更新进行时轮询轻量状态接口。

## 1.21 更新内容

- 固件 `1.204+` 的资源页显示 SD 卡总容量、已用容量、可用容量和真实占用比例。
- 低于 `1.204`、接口不存在或容量返回异常时，静默回退到原有的已管理资源统计。
- 上传、删除或手动刷新资源列表后会同步刷新 SD 卡容量。

## 1.20 更新内容

- 桌面端设备控制页与媒体资源页整体放大约 10%。
- 同步回收布局宽度，避免 1280/1366 等常见分辨率出现横向滚动。
- Wi-Fi 配网页、应用商店、创作指南和 780px 以下手机布局保持不变。

## 1.19 更新内容

- 恢复旧版的多语言应用名称解析顺序；首次加载本地 `app.info` 后缓存在页面会话中。
- 应用启动后只做一次短暂状态确认，不增加长期轮询。
- 当前应用显示“运行中”并隐藏“打开”；支持进入应用 WebUI 和安全退出。
- 右栏依次放置设备服务、连接状态、常用设置、媒体资源和系统更新，所有卡片按内容高度布局。
- 删除 `devrun → 文件管理器` 的旧名称映射。

## 1.18 更新内容

- 重构设备控制页和应用商店，区分官方应用与社区应用，并对接多语言名称和描述。
- 新增多语言应用创作指南、应用结构、`app.info` 字段说明和社区提交方式。
- 恢复 GIF 自动压缩及视频转码上传，上传阶段显示真实百分比、已发送和总字节数。
- 媒体资源按分类在固定高度面板内滚动；视频和音乐不在浏览器中加载或播放。
- 同目录、同名的 MP3/WAV 与 LRC 合并显示，并可分别下载或删除。
- 固件 1.204+ 支持查看、启动和停止服务；旧固件自动隐藏不支持的操作按钮。
- 修复图标重复刷新、移动端操作按钮换行和页面语言未同步等问题。

## 1.12 更新内容

- 修复手机浏览器中“图像管理”上传区域被通用 Hero 隐藏规则误隐藏的问题。
- 手机端“上传图片”和“上传 GIF”保持可见，并采用单列全宽按钮布局。

## 1.11 更新内容

- 完善 Launcher、Web 控制页、应用列表、服务页面和介绍页的中英文显示。
- 调整中文应用名称，并补充更多常用时区。
- 新增独立的“息屏与闹钟”服务页面，支持自动息屏、每日定时息屏与亮屏。
- 自动息屏在 Launcher 和其他 App 中均可生效，支持 HOME 按键或摇动设备唤醒。
- 支持三组闹钟，可选择每日、工作日、周末或指定星期。
- 支持内置“嘀嘀嘀”提示音及 SD 卡中的 MP3 铃声。
- 修复闹钟停止后因服务重载重复响铃、人工唤醒后再次息屏等状态问题。
- 修复 Web 保存后固件自动息屏设置未立即应用的问题。

“息屏与闹钟”服务的部署文件位于
`launcher/package/services/display_schedule/`，Launcher 会在需要时安装或更新该服务。
